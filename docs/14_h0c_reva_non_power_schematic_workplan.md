# 小熙 Hushlight H0C Rev A 非电源图页施工工作包

> 版本：V0.3  
> 日期：2026-08-14  
> 状态：只读审计完成；06 页器件级 P1-02 已关闭并发布第一批 A 表；供 `02–07` 与 Head 后续施工排队  
> 保护边界：`01POWERUSB` 为用户人工接线保护区，本工作包不授权移动、增删、改线或改网

## 1. 当前结论

现阶段不适合同时在多页盲目补件。安全且高收益的顺序是：先完成 `01POWERUSB` 第 44–77 项并截图复核；随后优先收敛 `02-MCU-DEBUG` 的 Base-S3 最小系统和唯一 I²C 上拉；再收敛 `06-MOTION-IO` 的 DRV8833 电源与安全默认外围。音频模拟链、FFC、静音硬断链、编码器/限位、摄像头与 Head GPIO 都仍受 Gate 约束，不为“页面看起来完整”提前连线。

首轮只读检查没有执行设计修改。2026-08-14 后续获授权施工只修改了 06 页两颗错误器件：C25/C28 完成真实料号替换并保存；`01POWERUSB` 仍未被移动、增删、改线或改网，未运行 ERC、未转 PCB。

## 2. 图页实况与下一动作

| 图页 | 本轮可直接确认的画布对象 | 判定 | 下一动作 |
|---|---|---|---|
| `02-MCU-DEBUG` | 对象树确认 21 件：`C9…C13、J5、R6…R9、R45、SW1/SW2、TP1…TP6、U1/U13`；`R45` 位于图框外 | `A+B`，第一批 A 表已发布 | 先把 R45 移入 U13.INT 附近，再按 11 的 `02-A01…A38` 接电源/EN/BOOT/TCA9554；J5、TP 和未分配 GPIO 暂不接 |
| `03-AUDIO-IN` | 对象树确认 17 件；画布可见 ES7210、两颗模拟麦、`U16` 麦克风 LDO、`C52…C55`、调试点和若干 codec 去耦 | `A+B+GATE` | 只开放 LDO 和数字电源去耦；模拟麦输入、AEC、偏置、3PDT 静音链等待 `H-MIC-001` |
| `04-AUDIO-OUT` | 对象树确认 13 件；画布可见 `U3=ES8311`、`U2=NS4150B`、`J9`、`C19…C24`、`R10/R11`、`TP11` | `B+GATE` | 先逐段清查旧的未命名线；只保留能证明端点和网名的导线。BTL 两端均不得接地 |
| `05-HEAD-LINK` | 对象树确认 13 件：`FPC1、C41…C43、R20…R28`；当前视图存在图框外对象 | `GATE` | 先把对象收回图框并核对位号，不接 FPC1；等待 `H-FFC-001/H-IO-001` 冻结料号、同异面、Pin 1 和针序 |
| `06-MOTION-IO` | 对象树确认 9 件：`C25…C29、R12/R13、U8/U9`；C25 已为 `C86018/2.2µF`，C28 已为 `C77053/10nF` | `A-PARTIAL+GATE` | 器件级 P1-02 已关闭；先布局 U9 与 VM/VCP/VINT/nSLEEP/nFAULT 外围，再按 11 的 `06-A01…A33` 接线。GPIO2、电机、编码器、限位保持 Gate |
| `07-CONNECTORS-TEST` | 可见 `CN1/CN3/CN4/CN5/CN6/CN7`、`SW4=SS-12D07-6` 候选、`LED1/R15`、`H1…H4` 等候选接口 | `B+GATE` | 保留候选但不接线；最终静音开关触点、服务口针序和线束座必须由实物/机构 Gate 冻结 |
| `H0-HEAD-REVA` | 2026-08-14 逐页打开复核：`00-SYSTEM`、`01-DISPLAY-TOUCH`、`02-CAMERA-PRIVACY`、`03-FLEX-TEST` 均只有 A4 图框，实际元件/网络/导线均为 0 | `GATE/NOT STARTED` | 不是等待 Base 接线完成；先冻结显示模组/FPC、Head 计算模组扩展口、摄像头座与隐私开关接口，再开始放件 |

“画布可见”只代表当前截图能确认符号存在，不代表元件值、封装、网络、BOM、ERC 或可采购状态。

## 3. 非 01 页施工序列

### N01：02 页实际位号清点

1. 已确认 21 个实际位号；`R6/R7` 冻结为 SCL/SDA 唯一上拉，`R8/R9` 冻结为 EN/BOOT 上拉。
2. `R45` 只服务 TCA9554 `INT`，接线前移入图框内 U13 附近。
3. 核对 Base-S3 模组的所有 3V3/GND、EN、GPIO0、USB D+/D−、UART0 和天线禁布区。
4. 第一批逐条、单源到单目标的 `02-A01…A38` 已发布到 11；截图复核前不扩展 J5/TP/USB/UART。

### N02：02 页最小系统接线

按以下功能块分批，每批截图复核后再进入下一批：

1. `BASE_3V3/GND` 与近端 `22µF + 10µF + 100nF`。
2. EN 上拉、RC 和 RESET；GPIO0 上拉和 BOOT。
3. TCA9554 电源、地址脚、唯一 I²C 上拉和 `R45.INT`。
4. Base USB D+/D− 与服务 UART；不接未冻结 GPIO。

### N03：06 页外围实物复核

必须先确认下列功能件是否实际存在，并映射到真实位号；不存在才补放，存在则禁止重复放置：

| 功能 | 冻结起始值 | 状态 |
|---|---|---|
| `C_VM` | `C27=10µF + C26=100nF`，贴近 U9.VM | 已核对，可保留 |
| Motor bulk | `C29=470µF`，位于 MOTOR_5V/eFuse 后端 | 已核对，可保留 |
| `C_VCP` | `C28=GRM188R71H103KA01D/C77053`，10nF 50V X7R 0603，跨 VCP–VM | 已完成真实器件替换、属性复核并保存 |
| `C_VINT` | `C25=GRM188R71A225KE15D/C86018`，2.2µF 10V X7R 0603，VINT–GND | 已完成真实器件替换、属性复核并保存 |
| `R_SLEEP_PD` | `R12=10kΩ`，nSLEEP 默认下拉 | 已核对，可保留 |
| `R_FAULT_PU` | `R13=10kΩ`，nFAULT 开漏上拉 | 已核对，可保留 |
| AISEN/BISEN | Rev A 直接到 GND；改采样需重开 Gate | 待接线前引脚复核 |
| PowerPAD | GND，并按散热焊盘处理 | 待接线前封装复核 |

GPIO2→BIN1、编码器、限位、电机座和保护/吸收网络继续保持 Gate，不能混入本批 A 表。

### N04：03/04 音频页

1. 先删除或明确命名旧的无端点证明线段；不以绿线颜色作为已连接证据。
2. 先接数字电源、地和本地去耦，再接已冻结的 I²C/I²S 数字网。
3. 模拟麦、AEC、Codec→功放和 BTL 输出各自单独评审；每一处模拟连接都要能追溯到 datasheet 应用图。
4. 静音必须保留“硬件切断采集 + 独立红灯 + 软件状态检测”三层，不把 TCA9554 当唯一安全路径。

### N05：05/07/Head Gate 页

只做清点、布局和功能位占位，不做最终连线。Gate 关闭至少需要：实物连接器、线束同异面、Pin 1 照片、触点真值表、模块扩展口原理图和机构装配证据。

#### Head 四页启动条件

| 图页 | 当前实况 | 首批允许放置的前置条件 |
|---|---|---|
| `00-SYSTEM` | 空白，0 元件 | `H-IO-001` 冻结 HEAD-S3/显示模组/摄像头三者的供电与跨页网络后，只放框图、电源入口和页间端口 |
| `01-DISPLAY-TOUCH` | 空白，0 元件 | 取得 600×450 AMOLED 实际采购型号、FPC 针数/间距/同异面、Pin 1 图和触控控制器 datasheet |
| `02-CAMERA-PRIVACY` | 空白，0 元件 | 冻结摄像头模块与座子型号、数据制式、供电时序、隐私 LED 硬件路径和快门/遮挡检测真值表 |
| `03-FLEX-TEST` | 空白，0 元件 | `H-FFC-001` 冻结底座/头部连接器、30Pin 一一映射、线束同异面、ESD 阵列与可测测试点 |

四页可以在 Base 尚未接完时并行施工，但必须先关闭各自接口 Gate。Base 的 `05-HEAD-LINK` 只提供已批准的 30Pin 网络契约，不能代替 Head 侧真实模块资料。

## 4. AI 可继续自动化的工作

| 工作 | 是否可无人值守执行 | 约束 |
|---|---|---|
| 只读统计图页、位号和值 | 可以 | 工程数据库只读；GUI 不进入 01 画布编辑；Head 四页已确认均为 0 元件 |
| 生成单点接线表草案 | 可以 | 只发布已冻结 A 项；B/GATE 不混入 |
| 检查文档序号、禁接项和链接 | 可以 | 使用 `scripts/validate_hardware_docs.py` |
| 02/06 补放已冻结且实际缺失的外围 | 条件允许 | 必须先完成实际位号清点；新增件先放框外待复核，不自动连线 |
| 03/04 模拟链连线 | 不可以 | 等 datasheet 级 pin mapping 与 `H-MIC-001` |
| 05/07/Head 最终连接器和针序 | 不可以 | 等实物/机构/线束 Gate |
| ERC、转 PCB、BOM、采购 | 不可以 | 分别需要完整连线、豁免记录和单独放行 |

## 5. 下一次交接点

用户返回后优先继续 `01POWERUSB` 第 44–77 项并按局部网络截图复核；该页完成前，AI 不进入其画布。并行工作优先级为：按已发布 A 表整理并连接 02/06 的确定项；Head 四页暂不盲放，先收集并冻结显示 FPC、Head 模组扩展口、摄像头/隐私机构和 30Pin 线束四类实物资料。
