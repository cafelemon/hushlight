# Base `07-CONNECTORS-TEST` 任务清单

> 本页当前为候选连接器/控件页。编号用于并行清点；在机械和线束 Gate 关闭前不发布逐脚接线。

| 编号 | 任务 | 当前对象 | 状态 | 关闭证据 |
|---:|---|---|---|---|
| 1 | EC11 旋钮 A/B/SW 与公共端真值表 | `SW3` 候选 | GATE | 实物料号、触点图、旋转方向 |
| 2 | 选择旋钮消抖方案 | RC 或软件二选一 | GATE | 固件/硬件共同决策 |
| 3 | 冻结 3PDT 锁定静音开关 | 当前 `SW4=SS-12D07-6` 不满足 3PDT 证明 | GATE | 真实型号、3 组独立触点、额定值、开孔 |
| 4 | 冻结硬件静音供电链 | `MIC_2V8_LDO → 开关 → MIC_2V8` | GATE | 断线/松脱默认静音实测 |
| 5 | 冻结独立红色 MUTE LED 路径 | `LED1/R15` 候选 | GATE | MCU 断电仍能反映硬件静音状态 |
| 6 | 冻结 `MUTE_SENSE` | Base GPIO39 | GATE | 高低电平/断线真值表 |
| 7 | Base 服务口针序 | `H1` 候选 | GATE | `GND/3V3/TX/RX/EN/BOOT` 实物方向 |
| 8 | Motion 服务口针序 | `H2` 候选 | GATE | 同上，核对 C3 UART/绑带 |
| 9 | Head 服务口针序 | `H3` 候选 | GATE | 与自研 Head-S3 的 USB/UART 恢复路径和 IPS/触控 FPC 无冲突 |
| 10 | 预留扩展服务口归属 | `H4` 候选 | GATE | 业务所有者与针序 |
| 11 | 扬声器座 | `CN1` 候选 | GATE | 4Ω/3W 扬声器、极性、线束 |
| 12 | PAN 电机座 | `CN3` 候选 | GATE | 电机额定/堵转/线序 |
| 13 | TILT 电机座 | `CN4` 候选 | GATE | 同上 |
| 14 | PAN 编码器座 | `CN5` 候选 | GATE | MT6701 输出制式和线序 |
| 15 | TILT 编码器座 | `CN6` 候选 | GATE | 同上 |
| 16 | 两路常闭限位座 | `CN7` 等候选 | GATE | 断线故障、上电绑带和线序实测 |

缺件规则：本页暂不新增静音开关、电机/编码器/限位保护器件；这些选择均受实物尺寸、电气输出制式或线缆长度影响，官网参数不能替代样件 Gate。
