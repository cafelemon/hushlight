### V0 评审节点

1. 交互原型评审：首次使用、陪伴、音乐和消息发送。
2. 概要设计评审：Bridge 工具协议、状态和失败处理。
3. 自研硬件评审：原理图、PCB、BOM、摄像头、云台、3D 结构、BSP 与切换条件。
4. 功能规格评审：每个适配器的输入、权限和通过条件。
5. 子任务验收：每个工作包完成开发、测试和验收。
6. 集成验证：所有纳入 V0 的工作包验收完成后开始。
7. Go/No-Go 评审：依据 `04_acceptance_checklist.md`。

### V0 No-Go

- 非技术用户仍需要命令行或手动配置。
- 陪伴体验与普通聊天应用无明显差异。
- 音乐和轻行动失败率导致用户不再信任。
- 消息确认不能稳定阻止误发送。
- 用户普遍拒绝安装或授权 Bridge。
- 重度用户云成本无法被月卡覆盖，且没有可接受的限额方案。

## 4. V1 Alpha

### 范围候选

- 由 H0 自研主线演进的封测级桌面设备。
- 真实扬声器场景下 AEC 和自然打断。
- Bridge 正式签名、自动更新和回滚。
- 稳定结构化记忆和引用解释。
- 主动关怀策略与频率学习。
- 第二个本地平台或第二组适配器，仅在 V0 证据支持时加入。
- 50 至 100 名成年用户封测。

### Alpha Gate

- P95 首段语音低于 2.8 秒。
- 设备连续运行 7 天无严重崩溃。
- Bridge 安装、更新、暂停和卸载通过。
- 未确认外部动作数为 0。
- 用户能区分陪伴价值和自动化价值。
- 主动关闭率、记忆纠正率和云成本进入可接受区间。
- 安全红队、隐私删除和工具注入测试通过。

## 5. V1 Pilot

### 范围候选

- 小批量结构、声学和生产测试。
- 设备注册、证书、OTA、灰度和回滚。
- 月卡、用量、免费额度和成本路由。
- 数据导出、删除、投诉和售后诊断。
- 应用签名、分发和版本支持策略。
- 200 至 500 台试销。

### Pilot Gate

- 完成适用的合规评估和发布签字。
- 硬件不良率、退货率和售后成本可接受。
- 活跃用户单位经济性符合套餐。
- Bridge 和适配器更新不会破坏核心陪伴。
- 售后、回滚、删除和应急流程可运行。

## 6. V2 候选

- Windows/macOS 双平台完整支持。
- 更多音乐和聊天适配器。
- 多款 Web 与设备角色风格。
- 可选开放工具生态。
- 手机端轻入口。
- 视觉、运动或轻触觉的后续扩展能力。
- 企业或创作者扩展能力。

V2 候选不属于当前承诺。
