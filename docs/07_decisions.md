### D-021 H0C USB-C CC 保护与 I²C 上拉收敛

| 项目 | 内容 |
|---|---|
| 状态 | Accepted；关闭 P0-01、P0-02 |
| 日期 | 2026-08-13 |
| 决策 | `J_USB1.CC1/CC2` 直接连接 `U5.STUSB4500QTR.CC1/CC2`，采用 STUSB4500 的 CC 短接 VBUS 内置 22 V 保护；删除错误的 `D4=TPD2E2U06DRLR`。`SYS_I2C` 只保留 `02_I2C_UI_DEBUG` 的 `R_I2C_SCL/R_I2C_SDA=4.7kΩ` 上拉，删除 `01POWERUSB` 的 `R30/R31`。 |
| 原因 | 原 D4 的工作电压不覆盖 USB-C CC 可能承受的 VBUS 误接条件；两组 4.7kΩ 并联会使上拉等效为约 2.35kΩ，增加低电平灌电流并破坏唯一总线基线。STUSB4500 已覆盖本次 P0 所需的 CC 误接保护；另加 TPD2S300 会引入 VPWR/VM/VBIAS 与死电池模式依赖，首板不作为默认方案。 |
| 影响 | 原理图中不再出现 D4、R30、R31；CC 与 I²C 点对点清单以 `11_h0c_reva_schematic_wiring_handoff.md` V0.6 为准。外露 CC 端口的系统级 IEC ESD 验证单列 P1，未因 P0 关闭而豁免。 |

### D-022 H0C Head 显示计算模组与视觉备份接口

| 项目 | 内容 |
|---|---|
| 状态 | Accepted |
| 日期 | 2026-08-14 |
| 决策 | Head 首板采用 Waveshare `ESP32-S3-Touch-AMOLED-2.41` 成熟显示计算模组 + 自研四层 Carrier。Carrier 必须预留独立视觉模组接口；先执行 `H-IO-001`，仅当模组扩展 GPIO 可安全承载所需 DVP 与低速接口时才直连摄像头，否则改用独立 XIAO ESP32-S3 Sense/等效视觉模块。 |

### D-023 H0C 摄像头、视场与隐私边界

| 项目 | 内容 |
|---|---|
| 状态 | Accepted |
| 日期 | 2026-08-14 |
| 决策 | 首板视觉输入采用 `OV3660` DVP 固定焦模组，水平视场角为 `100°±10°`，镜头置于屏幕上方中心。视觉仅在用户主动唤醒/对话期间工作，以 `640×480`、10–15fps 级别在头部本地输出目标坐标、置信度与时间戳；不存储、不向 Base、云端、Web 或 Bridge 输出原始帧。 |
| 原因 | 该视场在 0.45–1.5m 的电脑旁使用距离兼顾首帧覆盖、人脸有效像素与边缘畸变；OV3660 与 ESP32-S3 的软件路径成熟，固定焦避免自动对焦噪声与云台跟随抖动。 |
| 影响 | `H-CAM-001` 按模组的真实 FOV、焦距、排线、低照度、功耗与屏幕上方中心安装验证。OV5640 自动对焦仅保留为近距手势/拍摄需求的备选；120°以上超广角不作为默认。隐私灯必须随摄像头供电硬件联动，机械遮挡另行冻结。 |

### D-024 H0C 双轴执行机构基线

| 项目 | 内容 |
|---|---|
| 状态 | Accepted |
| 日期 | 2026-08-14 |
| 决策 | 首板采用两台 6V 有刷金属减速直流电机，各自配外置 `MT6701` 输出轴角度传感器与二级同步带传动；减速比目标为 1:100–1:150。单轴电机额定工作电流不高于 0.5A、堵转电流不高于 1.2A、输出端连续扭矩不低于 0.08N·m。Pan 行程为 ±70°，Tilt 行程为 −20° 至 +35°，最高角速度 80°/s；Head 重心须落在 Tilt 轴附近。每轴保留一个独立常闭机械硬限位。 |
| 原因 | 该组合与既定 `MOTION-C3 + DRV8833` 架构匹配，能以闭环、限加速度/限加加速度的方式实现安静、可控的跟随，同时保留电机、传动和控制算法分别排障的能力。相比舵机，能消除待机抖动与明显的机械玩具感；相比无刷云台+FOC，首板风险和联调量可控。 |
| 影响 | 此处冻结的是选型包络和机械路线，不是具体电机 SKU。硬件线须在 Head 实物质量、重心、转动惯量和线束阻力测量后，以堵转电流、热、噪声、回差和实际输出扭矩筛选具体电机/同步带规格；无刷 FOC 仅保留为后续高静音版本的备选。 |

### D-025 H0C 编码器、回零与硬限位基线

| 项目 | 内容 |
|---|---|
| 状态 | Accepted |
| 日期 | 2026-08-14 |
| 决策 | 每轴采用 `MT6701 SOP-8` + 径向充磁磁铁，使用 A/B 正交增量输出直连 `MOTION-C3`；每轴保留一个独立常闭机械限位开关。上电、驱动故障恢复或编码器异常后，设备必须低速向对应硬限位回零并建立零位。 |
| 原因 | 当前 C3 已为两轴 A/B 提供四条专用输入，直连闭环路径最短、实时性和抗干扰调试最可控。MT6701 保留 SSI/I²C/绝对角度等升级能力，但首板不为绝对角度增加五条 SSI 信号或 I²C 地址复用风险。 |
| 影响 | 硬限位不得承担日常行程控制：运行行程由编码器闭环和软件软限位控制，硬限位只用于回零终点与独立故障兜底。`H-ENC-001` 须验证磁铁同轴度、气隙、线束干扰、回零重复精度与断电重启后的恢复时间。 |

### D-026 H0C 双麦与声学结构基线

| 项目 | 内容 |
|---|---|
| 状态 | Accepted |
| 日期 | 2026-08-14 |
| 决策 | 采用两颗同批次 `Infineon IM73A135V01` 模拟差分 MEMS 麦克风，接入既定 `ES7210`。麦克风固定于 Base 上前方左右两侧，不随 Head 云台运动；左右中心间距目标 70–90mm，各自具备独立小音腔、金属网和防尘透声膜。扬声器保持下部/后部，与麦克风直线距离目标不小于 120mm，并采用结构隔振。 |
| 原因 | 差分模拟输出直接匹配 ES7210，避免首板引入 PDM 时钟、数字音频和 AEC 链路重构。IM73A135V01 的高 SNR、高 AOP 与配对一致性将预算投入到桌面远场拾音、播报打断和稳定陪伴感，而不是过早堆叠四麦阵列。 |
| 影响 | 结构与声学 Gate 须在云台运动和 60% 播放音量下验证 AEC、打断与 ASR；若失败，优先排查麦克风隔振、扬声器指向/距离、音腔与 AEC 参考通路。PDM 双麦和四麦阵列不进入 H0 首板。 |

### D-027 H0C Head 动态线束与连接器基线

### D-028 H0C 可信静音与相机隐私硬件边界

### O-006 模型和成本路由

已确认自建训练资产、SFT/DPO、“4B 主力 + 9B/强模型 Fallback”方向和 V0 云端主推理路线；仍需确定 ASR、声学情感、TTS、具体 Companion Model/Teacher/Judge/Fallback 版本、路由阈值、训练平台、云端 Provider、限额、失败切换和单位成本。

2026-08-14 已补充 `Qwen3.5-4B-MLX-4bit` 在 M5/24GB 上的单条 CompanionState 与本地 API POC：指定疲惫场景通过，生成约 7.06 秒、峰值内存约 4.34GB。该证据只缩小本地 4B 推理不确定性，不关闭 O-006，也不证明 Gold Set、LoRA、长稳、并发、设备闭环或成本通过。

关闭 O-006 前至少完成：500 条 Gold Set、Base/SFT/DPO/Teacher/Character 对比、模型级行动候选误报与系统级零执行区分、语音全成本表、Provider 故障降级和模型版本锁定策略。具体候选不得因本机 MLX 测试通过而写成 V0 上线模型。
