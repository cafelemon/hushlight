# Hushlight Web 决策记录

## WEB-D-001 使用模块化单体 SPA

| 项目 | 内容 |
| --- | --- |
| 状态 | Accepted |
| 日期 | 2026-08-13 |
| 决策 | W0 使用 React + TypeScript + Vite，按 App/Pages/Features/Domain/Data/UI 分层 |
| 原因 | 适合控制台演进；保持部署简单；无需提前引入微前端或 SSR |
| 影响 | 若未来出现公开营销站或 SEO 需求，另行评估，不与控制台混为同一渲染目标 |

## WEB-D-002 W0 使用可替换的本地预览数据源

| 项目 | 内容 |
| --- | --- |
| 状态 | Accepted |
| 日期 | 2026-08-13 |
| 决策 | 页面依赖 Repository 接口；内存实现必须返回 `source: preview` |

## WEB-D-003 暂不引入大型 UI 和数据框架

| 项目 | 内容 |
| --- | --- |
| 状态 | Accepted |
| 日期 | 2026-08-13 |
| 决策 | W0 使用原生 CSS Token；TanStack Query 延迟至 W1 |
