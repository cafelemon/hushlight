# Hushlight Web 项目总览

> 文档版本：V0.1  
> 更新日期：2026-08-13  
> 阶段：W0 工程骨架

## 1. 项目目标

Hushlight Web 是小熙的低频配置与管理大本营，承载账户、设备、角色与陪伴模式、PC Bridge、权限、记忆、最近操作、订阅和诊断入口。日常陪伴仍以设备和语音为主，Web 不直接控制任意本地应用。

W0 交付一个可运行、可扩展、能诚实表达未接入状态的前端骨架，为云端 API 和真实设备接入预留稳定边界。

## 2. 当前交付

- React + TypeScript + Vite 单页应用。
- 桌面优先、移动端可用的控制台布局。
- 总览、设备、陪伴设置、Bridge 与权限、记忆、活动记录、账户与订阅七个入口。
- 本地演示数据仓库，页面明确标记“本地预览”，不表示云端、设备或 Bridge 已接入。
- 可替换的数据访问接口、统一领域类型、错误与空状态基线。
- 类型检查、单元测试和生产构建命令。

## 3. 当前边界

- 不实现真实登录、扫码绑定、云端 API、订阅支付或安装包下载。
- 不发送消息、不控制设备、不调用本地软件。
- 本地切换仅用于验证交互，刷新后恢复初始预览状态。
- 不把 Mock 状态作为真实联调或用户验收证据。
