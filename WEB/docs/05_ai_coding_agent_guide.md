## 2. 实现规则

1. 页面只通过 `HushlightRepository` 读写业务数据。
2. `preview` 与 `live` 数据源在领域模型和界面上都不可混淆。
3. 设备、Bridge 和权限状态未知时显示未知或未连接，不猜测成功。
4. 新页面必须补齐加载、空、错误、禁用和移动端状态。
5. 不把凭据、真实联系人、聊天正文或设备令牌提交到仓库。
6. 不在浏览器直接控制本地软件或绕过消息确认链路。
7. 先更新拥有规则的文档，再实现新的角色、状态、权限或验收行为。

## 3. 完成定义

- 类型检查、相关测试和生产构建通过。
- 桌面与移动目标视口完成实际像素检查。
- 失败与空状态有验证证据。
- 文档和进度同步，未验证范围明确。
- 不覆盖根目录或其他子项目的用户修改。
