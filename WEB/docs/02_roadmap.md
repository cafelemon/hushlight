# Hushlight Web 路线图

| 阶段 | 目标 | 主要 Gate |
| --- | --- | --- |
| W0 骨架 | 文档、设计系统、路由、页面壳、本地预览数据、基础测试 | 类型检查、测试、构建、桌面/移动检查 |
| W1 接口联调 | 登录态、账户、设备列表、配置读取与保存 | API 契约冻结；错误、超时、空状态通过 |
| W2 首次使用 | 扫码绑定、Bridge 下载、自动绑定、按需权限引导 | 非技术用户不接触命令行；首个动作闭环 |
| W3 管理闭环 | 记忆 CRUD、活动追踪、订阅与诊断 | 删除后不再引用；结果来源真实；审计可追踪 |

## W0 非范围

- 后端、数据库、身份供应商和支付供应商选型。
- 真实设备、Bridge 或本地应用控制。
- 多套主题、营销官网和公开发布。
