# 当前建议：不要集成无效捕获绕行

本机已完成独立对照。动态过滤器普通D无帧；设置预热D2虽然返回新帧，但3次均黑帧且无固定测试串，不能集成为“微信可读”。

Core Graphics明确把聊天窗标为none，设置窗readOnly；4.1.13与已验签并登录的4.1.15均如此。停止穿透尝试。此事实支持将当前状态判为窗口共享受限，但不能证明内部调用方/触发原因。

最小生产改动是区分sharingRestricted与权限未授予，避免循环申请；不修改捕获API、不重签/注入微信、不取钥读库、不重置TCC或SIP。后续若官方公开版本/设置恢复共享，先读元数据再用固定测试串和重复矩阵验收。记录失败路径，避免重新建议不存在的设置或把官方版本切换说成已成功。

完整运行证据见results.md与logs；本地操作手册见../../docs/14_wechat_capture_troubleshooting.md。用户授权的真实单聊测试尚未发送，保持待执行。
