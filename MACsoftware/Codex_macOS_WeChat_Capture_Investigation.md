# Codex 任务书：macOS 微信聊天窗口截图白屏专项排查

> 状态：待验证 · 目标：定位原因并寻找稳定、合规的捕获路径 · 优先级：P0

## 1. 背景与已确认事实

当前产品是 **macOS 原生 Agent 工作台**，使用系统辅助功能（Accessibility）和屏幕捕获，让 Agent 观察并操作桌面软件。

用户已确认：

- 其他软件截图正常，只有微信聊天界面异常。
- 微信设置页可以正常捕获。
- 微信主聊天窗口正文显示为空白；用户本人在屏幕上可正常看到内容。
- 已尝试独立聊天窗口：可以读取联系人标题，但正文仍然白屏。
- 微信设置中找不到“演示屏幕时不显示微信主窗口”选项。
- 当前只考虑 **macOS**，不需要 Windows、Android 或移动端方案。

**不要**重复建议用户检查通用屏幕录制权限或寻找不存在的设置；除非实验日志提供了明确证据。

## 2. 目标与验收标准

1. 区分“窗口捕获失败”“聊天正文被保护/排除”“UI 元素不可访问”“截图实现 bug”等不同原因。
2. 在不修改、不注入微信进程的前提下，评估 macOS 官方 API 能否稳定捕获聊天正文。
3. 将实验与现有产品解耦，先做独立 Swift 原型。
4. 若找到可行方案，提供最小集成建议、兼容性边界、回退路径和风险说明。
5. 若不可行，给出证据充分的失败结论，不能把推测当成修复结果。

成功不只是拿到一帧：**需要截图能看清用户预置的无敏感信息测试聊天正文**，并在重复测试中保持稳定。

## 4. 先检查现有代码（只读）

请先调查现有工作区并输出：

- 当前截图调用链：Agent → 工具接口 → 捕获服务 → macOS API → 图像传输/编码。
- 使用的具体 API：`SCScreenshotManager`、`SCStream`、`CGWindowListCreateImage` 或其他。
- 微信窗口识别依据：bundle ID、PID、窗口 ID、标题、层级。
- 是否有图片裁剪、透明通道、色彩空间、像素缓冲、编码或缓存问题。
- Accessibility 树中微信主窗口、独立聊天窗口、设置窗口分别暴露哪些元素。

**不要直接修改生产代码。** 在实验完成前，只形成现状记录。

## 5. 独立实验矩阵

创建 `experiments/wechat-capture/`，以 Swift 实现最小可运行程序。先读取当前系统和微信版本，记录授权状态与设备架构。

| 编号 | 实验 | 目的 |
|---|---|---|
| A | 标准单窗口截图（可用时用 `SCScreenshotManager`） | 建立失败基线 |
| B | `SCStream` + `desktopIndependentWindow` | 对照流式单窗口捕获 |
| C | `SCStream` + 应用级过滤器 | 判断应用级捕获差异 |
| D | 先启动应用级流，再 `updateContentFilter` 切换目标窗口 | 验证社区提及的动态过滤器现象 |
| E | 显示器级捕获 | 比较全屏与单窗口的可见性 |
| F | Accessibility 树检查 | 判断能否通过语义元素读取聊天正文 |
| G | 微信设置页与其他普通软件对照 | 排除工具链的通用故障 |

实验 D 建议顺序：

1. 枚举 `SCShareableContent`，准确识别微信应用、显示器和目标窗口。
2. 创建应用级 `SCContentFilter`、`SCStreamConfiguration` 和 `SCStream`。
3. 注册帧输出，启动捕获，并确认收到有效帧。
4. 等待短暂稳定时间（例如 250 ms，仅作为实验参数）。
5. 对同一 `SCStream` 调用 `updateContentFilter(...)` 切换目标窗口。
6. 再次接收帧并与基线比较；记录 API 返回值和异常。
7. 进行重复启动与连续捕获测试。

**重要：** 以本机 SDK 类型签名为准，不能直接照抄未经编译验证的网络片段。若 macOS 或微信有明确的隐私保护限制，停止尝试绕过，转为记录受限状态并评估用户授权的替代工作流。

## 6. 测试规范

- 使用专门的测试聊天窗口，消息内容采用固定、非敏感的测试字符串。
- 禁止上传真实聊天内容、联系人资料、会话数据库或屏幕截图到外部服务。
- 测试图片只保存在本地实验目录，必要时脱敏。
- 每个实验至少记录：macOS 版本、微信版本、API、过滤器类型、窗口 ID、是否返回帧、图像尺寸、聊天正文是否可读、耗时、错误信息。
- 不得只通过“像素非白色”判断成功，必须人工确认测试字符串可见。
- 对初步成功的方案，进行多次冷启动、连续捕获和窗口切换验证，并记录失败率。
- 如需触发系统权限弹窗，应先向用户说明并等待授权。

## 7. 安全与范围约束

禁止：

- 修改、重签名或注入微信客户端。
- Hook 微信内部函数、绕过进程保护或提取聊天数据库密钥。
- 读取、保存、发送真实聊天数据。
- 在没有明确授权的情况下自动发送微信消息。
- 为了让截图看起来成功而伪造测试结果。

允许：使用 macOS 公开 API 进行只读诊断；基于测试数据验证辅助功能树和捕获结果；为用户可见、已授权的交互设计安全回退。
