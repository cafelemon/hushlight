## 2. 阶段一：局域网研发闭环

### 2.1 工作包

| 工作包 | 交付 | 退出证据 |
| --- | --- | --- |
| S1-W1 开发 App 基础 | Xcode `.app` target、`com.hushlight.bridge.mac`、Development signing、权限声明、菜单栏/窗口/Dock 开关 | 开发 App 启动和权限状态录像 |
| S1-W2 协议与测试台 | `bridge-v1`、Bonjour、WSS、配对、Keychain、防重放、Debug 测试台 | 协议自动测试 + 真实设备配对录像 |
| S1-W3 系统能力 | 音量、计时器、提醒事项、白名单打开、通用媒体控制 | 自动测试 + 系统状态回读 |
| S1-W4 网易云适配（暂缓） | 按用户最新决定跳过 | 不进入当前开发和验收队列 |
| S1-W5 微信适配 | 联系人查找、草稿、确认、发送、幂等和未知结果 | 测试账号安全 Gate + 红队记录 |
| S1-W6 集成与长稳 | 设备/测试台同路由、权限恢复、暂停、诊断、8 小时长稳 | 集成报告 + 长稳日志 |

D-MAC-014 覆盖原串行限制：无硬件时继续核心、CLI、系统与应用适配器的软件工作，先通过软件专属 Gate，再补真实设备集成 Gate。同一开发者可按已具备的软件依赖推进 W2/W3；适配器技术研判可在 W2 后并行穿插，但不得用未验证推断提前关闭 Gate。

### 2.2 当前离线进展

- S1-W2 已部分完成：JSON Schema 资源、Swift 强类型协议、17 个 action 参数约束、版本/时效/结构校验、nonce 防重放、`PolicyEngine`、`CommandRouter`、统一 `BridgeCommandProcessor` 和 500 条/7 天结果幂等缓存。
- 已用内存适配器证明暂停、风险不匹配、能力未实现、并发重复请求、新 nonce 重试，以及 L3 HMAC 签名、完整字段绑定和确认单次使用行为。
- 尚未完成：LAN Envelope HMAC 验签、配对/Keychain、Bonjour/WSS、Debug UI、真实设备契约，以及云端正式确认签发接口。
- 因上述缺口存在，S1-W2 和任何 S1 Gate 均未关闭。

### 2.3 无硬件软件 Gate（独立于设备 Gate）

- 本机模拟命令走完整校验、策略与路由；模拟结果显式标记。
- 默认真实读取可回读系统状态；真实写入须显式启用，拒绝/失败/未知不可显示成功。
- 暂停、过期、重放、未知能力与非本地来源有自动拒绝证据。
- 核心库与 CLI 可独立构建，Release 不包含模拟实现。
- 第三方应用软件验收可以由本机命令驱动，不等待设备；真实账号/支持版本仍需独立验收。

### 2.4 S1 设备集成 Gate

- [ ] Debug 测试台未绕过 `CommandRouter` 或 `PolicyEngine`。
- [ ] 真实设备通过 Bonjour 发现、配对并执行全部注册动作。
- [ ] 未配对、错误密钥、过期、重放和未知动作全部被拒绝。
- [ ] 系统音量、两类提醒、白名单内容和媒体控制均返回真实结果。
- [ ] 网易云支持版本完成搜索播放和状态回读；不确定时返回 `unknown`。
- [ ] 微信只使用测试账号/联系人；联系人歧义停止，未确认发送数为 0。
- [ ] 暂停在执行边界立即拒绝全部本地动作。
- [ ] 连续 8 小时、至少 50 次动作循环无非预期重启或状态卡死。

### 3.3 S2 Gate

- [ ] Bridge 仅建立出站云端连接，用户不填写地址、端口或令牌。
- [ ] LAN 与 Cloud 对相同请求返回相同语义结果。
- [ ] 断线恢复不重放 L3；过期确认不得发送消息。
- [ ] 云端停用单个适配器不影响其他能力。
- [ ] Bridge 离线时设备仍可基础聊天，并明确本地能力不可用。
- [ ] 所有计划上市功能已完成开发、自动测试、手工验收和回归。
- [ ] 功能行为冻结；新增能力必须重新进入 PRD/架构评审。

## 5. 外部阻塞与排期规则

| 阻塞 | Owner | 影响 |
| --- | --- | --- |
| 网易云未安装或无可冻结测试版本 | macOS Owner | S1-W4 不得验收 |
| 微信测试账号/联系人不可用 | 产品/测试 Owner | S1-W5 不得执行真实发送测试 |
| 云端接口或环境未就绪 | 云端/Web Owner | 对应集成验收保持待验证，继续不依赖该环境的本地开发 |

| Apple 账号、证书或域名未就绪 | 项目负责人 | S3 不得启动正式发布 |

排期按工作包实际进入条件计算；外部等待、应用版本突变和 Apple 审核/公证异常单独记录，不压缩测试和安全 Gate。
