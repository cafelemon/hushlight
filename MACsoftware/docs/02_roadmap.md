# Hushlight Mac 版本规划

| 里程碑 | 交付 | 退出条件 |
| --- | --- | --- |
| M0 骨架 | SwiftUI 主窗口、菜单栏、领域模型、服务接口、测试与文档 | `swift build`、`swift test` 通过 |
| M1 连接 | 正式 App target、绑定、鉴权、心跳、重连、暂停拒绝、登录项 | 断网恢复不重放动作；暂停立即拒绝 |
| M2 基础动作 | 音量、提醒、白名单打开 | 实际系统状态可回读；失败不报成功 |
| M3 音乐 | 网易云播放、暂停、切歌、搜索与消歧 | 支持版本矩阵和重复测试通过 |
| M4 消息 | 微信草稿、消歧、确认、发送 | 安全 Gate 全部通过，未确认发送为 0 |
| M5 交付 | 安装、签名、公证、更新、回滚、诊断、卸载 | macOS 独立交付清单通过 |

每个里程碑必须同时完成代码、自动测试、手工验收记录和文档更新。
