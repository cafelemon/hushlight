# Hushlight Mac 开发地图

> 文档版本：V0.2
> 更新日期：2026-08-13
> 估算口径：1 名全职 Mac 开发者；不包含外部依赖等待时间

## 1. 阶段总览

| 阶段 | 目标 | 预计周期 | 进入下一阶段条件 |
| --- | --- | ---: | --- |
| M0 工程骨架 | 建立 SwiftUI 状态壳、服务边界和文档 | 已完成 | 现有构建和两项单元测试通过 |
| 阶段一：局域网研发闭环 | 全部本地能力通过真实设备和 Debug 测试台执行 | 9–11 周 | S1 Gate 通过 |
| 阶段二：云端完整闭环 | 接入云端长连接并冻结计划上市功能 | 5–7 周，不含等待 | S2 Gate 通过 |
| 阶段三：正式产品准备 | 官网 DMG、签名、公证、更新、回滚、卸载和兼容验证 | 4–5 周 | S3 Release Gate 通过 |

本路线不替代根项目 K0/V0/Alpha/Pilot。阶段一和阶段二属于 V0 软件验证，阶段三位于 V0 功能冻结之后并形成 Alpha 可交付基线。

## 2. 阶段一：局域网研发闭环

### 2.1 工作包

| 工作包 | 建议周期 | 交付 | 退出证据 |
| --- | ---: | --- | --- |
| S1-W1 开发 App 基础 | 1 周 | Xcode `.app` target、`com.hushlight.bridge.mac`、Development signing、权限声明、菜单栏/窗口/Dock 开关 | 开发 App 启动和权限状态录像 |
| S1-W2 协议与测试台 | 2 周 | `bridge-v1`、Bonjour、WSS、配对、Keychain、防重放、Debug 测试台 | 协议自动测试 + 真实设备配对录像 |
| S1-W3 系统能力 | 2 周 | 音量、计时器、提醒事项、白名单打开、通用媒体控制 | 自动测试 + 系统状态回读 |
| S1-W4 网易云适配 | 2 周 | 搜索播放、播放控制、曲目回读、版本停止条件 | 支持版本矩阵 + 重复测试录像 |
| S1-W5 微信适配 | 2–3 周 | 联系人查找、草稿、确认、发送、幂等和未知结果 | 测试账号安全 Gate + 红队记录 |
| S1-W6 集成与长稳 | 1 周 | 设备/测试台同路由、权限恢复、暂停、诊断、8 小时长稳 | 集成报告 + 长稳日志 |

同一开发者按 W1→W2→W3→W4→W5→W6 推进；适配器技术研判可在 W2 后并行穿插，但不得用未验证推断提前关闭 Gate。

### 2.2 S1 Gate

- [ ] Debug 测试台未绕过 `CommandRouter` 或 `PolicyEngine`。
- [ ] 真实设备通过 Bonjour 发现、配对并执行全部注册动作。
- [ ] 未配对、错误密钥、过期、重放和未知动作全部被拒绝。
- [ ] 系统音量、两类提醒、白名单内容和媒体控制均返回真实结果。
- [ ] 网易云支持版本完成搜索播放和状态回读；不确定时返回 `unknown`。
- [ ] 微信只使用测试账号/联系人；联系人歧义停止，未确认发送数为 0。
- [ ] 暂停在执行边界立即拒绝全部本地动作。
- [ ] 连续 8 小时、至少 50 次动作循环无非预期重启或状态卡死。

## 3. 阶段二：云端完整闭环

### 3.1 进入条件

- S1 Gate 通过。
- 云端/Web Owner、设备固件 Owner、测试 Owner 已指定。
- 登录绑定、令牌、WSS、能力快照和确认凭据接口完成评审。
- 有独立开发/测试环境，不使用生产账号或真实外部联系人。

### 3.2 工作包

| 工作包 | 建议周期 | 交付 | 退出证据 |
| --- | ---: | --- | --- |
| S2-W1 登录与绑定 | 1–2 周 | Web 登录回跳、Bridge/账户/设备绑定、短期令牌与 Keychain 刷新凭据 | 登录、注销、换机和令牌过期测试 |
| S2-W2 云端 Transport | 1–2 周 | 出站 WSS、心跳、重连、能力快照和服务端停用 | 断网、过期、重复和服务端撤销测试 |
| S2-W3 统一执行链 | 1 周 | LAN/Cloud 进入相同路由；阶段一行为无回归 | 契约测试和差异报告 |
| S2-W4 产品状态壳 | 1 周 | 在线、暂停、权限、最近动作、诊断和错误恢复 | UI 状态矩阵和可访问性检查 |
| S2-W5 全链路验收 | 1–2 周 | 设备→云端→Mac→应用→云端→设备反馈 | 全能力端到端录像和日志 |

### 3.3 S2 Gate

- [ ] Bridge 仅建立出站云端连接，用户不填写地址、端口或令牌。
- [ ] LAN 与 Cloud 对相同请求返回相同语义结果。
- [ ] 断线恢复不重放 L3；过期确认不得发送消息。
- [ ] 云端停用单个适配器不影响其他能力。
- [ ] Bridge 离线时设备仍可基础聊天，并明确本地能力不可用。
- [ ] 所有计划上市功能已完成开发、自动测试、手工验收和回归。
- [ ] 功能行为冻结；新增能力必须重新进入 PRD/架构评审。

## 4. 阶段三：正式产品准备

### 4.1 进入条件

- S2 Gate 通过且功能冻结。
- Apple Developer Program、Developer ID、正式下载域名和更新源可用。
- Sparkle `2.9.4` 完成许可证、安全和供应链评审并登记。

### 4.2 工作包

| 工作包 | 建议周期 | 交付 | 退出证据 |
| --- | ---: | --- | --- |
| S3-W1 发布身份 | 1 周 | Release 配置、Hardened Runtime、Entitlements、Developer ID | 签名审计和权限回归 |
| S3-W2 DMG 与卸载 | 1 周 | 官网 DMG、拖放安装、完整卸载说明和清理边界 | 全新账户安装/卸载录像 |
| S3-W3 更新与回滚 | 1–2 周 | Sparkle appcast、EdDSA、灰度渠道、失败回滚 | 正常/篡改/断网/失败更新测试 |
| S3-W4 发布矩阵 | 1 周 | macOS 13、上一主流版本、当前版本兼容和发布证据 | Release Readiness 记录 |

### 4.3 S3 Release Gate

- [ ] Developer ID、Hardened Runtime、`notarytool` 和 stapling 全部通过。
- [ ] 全新 Mac 不通过终端即可安装、首次配置、退出和卸载。
- [ ] 更新包和 appcast 签名验证通过；篡改内容被拒绝。
- [ ] 更新失败恢复上一可用版本，L3 确认和待执行请求不跨版本恢复。
- [ ] 用户选择开机启动；关闭后 `SMAppService` 不再注册。
- [ ] 权限拒绝、恢复、升级后保留和重新授权路径完成实机验证。
- [ ] 诊断包通过敏感字段检查。
- [ ] 版本匹配的代码审查、安全审查和发布就绪评估均通过。

## 5. 外部阻塞与排期规则

| 阻塞 | Owner | 影响 |
| --- | --- | --- |
| 网易云未安装或无可冻结测试版本 | macOS Owner | S1-W4 不得验收 |
| 微信测试账号/联系人不可用 | 产品/测试 Owner | S1-W5 不得执行真实发送测试 |
| 云端接口或环境未就绪 | 云端/Web Owner | S2 周期暂停计时并单列等待 |
| 设备协议实现未就绪 | 设备固件 Owner | 可用测试台推进，但 S1 Gate 不得通过 |
| Apple 账号、证书或域名未就绪 | 项目负责人 | S3 不得启动正式发布 |

排期按工作包实际进入条件计算；外部等待、应用版本突变和 Apple 审核/公证异常单独记录，不压缩测试和安全 Gate。
